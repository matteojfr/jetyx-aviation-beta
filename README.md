# Jetyx Aviation Beta — downloads

This repository only hosts the **Windows installers** of Jetyx Aviation Beta. It does not contain the source code.

- Download the latest version from **[Releases](../../releases/latest)**.
- Website: https://jetyxaviation.com
- Web app (iPad, iPhone, any browser): https://jetyxaviation.com/app/

The installer is not code-signed yet: Windows SmartScreen shows "Windows protected your PC", choose **More info → Run anyway**. Each release lists the installer's SHA-256 checksum.

Jetyx Aviation is an independent educational project, not affiliated with or endorsed by Airbus, EASA or any airline, and not certified training material.
